# 后端基准测试报告

> ⚠️ **本页内容已撤回。**
>
> 本页此前给出的 Node.js 与 Bun 对比（"Bun 领先 19%-171%" 等）存在两个问题：
>
> 1. **混淆变量**：`@veaba/qrcode-node` 与 `@veaba/qrcode-bun` 是两套**不同的实现**
>    （前者封装 `@veaba/qrcode-js-shared` 的 `QRCodeCore`，后者自带独立实现），
>    因此该对比同时变动了「运行时」与「实现」两个因素，既不能证明 Node 与 Bun 的快慢，
>    也无法归因到任一因素。
> 2. **数据不可复现**：本页展示的数值无法在 `docs/public/` 的任何数据文件中找到出处，
>    且仓库内另有两份独立抽样（原 `benchmark_node_result.json` / `benchmark_bun_result.json`）
>    得出**相反**结论（Bun 领先）。
>
> 相关数字与数据文件已一并删除。若需重新建立该对比，必须先**固定实现**
> （两个运行时加载同一份源码），并在独立进程中多轮重复取中位数。
